## Trampas del entorno (Windows / Git Bash) — anotadas para no repetirlas
- **`git commit -F - <<'EOF'` se cuelga si el comando pasa a segundo plano**: el heredoc
  queda esperando stdin. Usar un archivo de mensaje (`.git/COMMIT_MSG.txt`) y borrarlo
  después. Con `-F -` en primer plano funciona, pero si la herramienta lo manda a
  background por timeout, se traba.
- **`git push` puede parecer colgado y haber funcionado igual**: los intentos con
  `timeout` no imprimen nada y el proceso queda vivo. Verificar SIEMPRE con
  `git ls-remote --heads origin` / `git rev-parse origin/main` antes de reintentar o
  de asumir que falló. (El trace mostró un `401 Unauthorized` en un reintento, pero un
  push anterior ya había subido el commit.)
- El servidor de desarrollo de Vite tarda ~11 s en estar listo: un `curl` inmediato
  devuelve 000 y hace pensar que falló.
